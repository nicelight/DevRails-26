# DevRails Nav 27 — основные спецификации

Статус: проект контракта реализации, не свидетельство работающего плагина.
Цель — управляемая AI-разработка в DSH: код допускает и учитывает работу,
модели выполняют предметные задания, карта показывает реальное состояние.

## Основание и граница

[Решения пользователя](../DEVRAILS_NAV_27.md),
[autonomy policy](../skills/_shared/references/workflows/autonomy-policy.md) и
[tier policy](../skills/_shared/references/workflows/tier-policy.md) задают
принятую семантику. Эти спецификации определяют **как и почему** реализуется
DSH-плагин, не заменяя task schema, verdicts и ownership предметных команд.
[Каталог переходов](../docs/nav27/TRANSITIONS.md) остаётся единственным каталогом
маршрутов; [архитектура](../docs/nav27/ARCHITECTURE.md) — исследовательское
основание, а не дополнительный набор обязательных механизмов.

Последнее принятое уточнение пользователя: вызов H во время работы направляет
оркестратору prompt «обратись сейчас к судье для инспекции своих действий».
Он доставляется native `agent.steer` на ближайшей step boundary; ожидание
станции не требуется. Нажатие уже разрешает эту консультацию. Рекомендация
ждать ближайшей станции в прежних architecture/acceptance документах отменена.
Новые маршруты по результатам инспекции используют обычный consent contract.

В scope — один внешний подключаемый DSH bundle, один run на проект,
standalone Svelte 5/SVG, маленький native client addon, existing Memory Bank.
DSH core hooks/fork/rebuild, второй agent loop/task engine/chat log и реализация
плагина в рамках этого spec-пакета исключены. Ручное вмешательство через native
UI или файлы не превращается в задачу глобального policing.

## Ядро и traceability

| Понятие / цель | Canonical контракт | Почему отдельная граница |
| --- | --- | --- |
| Run: один владелец допуска и текущей позиции проекта | [Controller](controller.md) | Два UI и модель не должны независимо запускать одну работу. |
| Leg: одна операция или выбранная группа, один snapshot | [Controller](controller.md) | Настройки будущего verify меняются без повторного exe; текущие peers стабильны. |
| Decision: конкретное предложение и источник его разрешения | [Feedback](feedback.md) | Предметный verdict не является согласием или командой запуска. |
| Подключение к существующему DSH | [Architecture](architecture.md) | Сохраняются native execution, permissions, transport и sessions. |
| Продолжение фактической работы после обрыва | [Evidence](evidence.md) | Task results сильнее устаревшей позиции; история не переписывается. |
| Main, Side и карта | [Sessions/UI](sessions-ui.md) | Разговоры и анимация не получают lifecycle authority. |

[Spec graph](spec-graph.yaml) описывает зависимости документов, не runtime graph.
Контракты ниже нормативны для реализации; их приёмочные сценарии требуют
исполнения будущего плагина. Source baseline DSH:
`ce7073d51254c26cd63b22a60835b8f948deb447`. Исследование исходников подтверждает
seams, но не сборку, доставку или runtime enforcement. Точная визуальная
геометрия согласуется до оформления UI и не блокирует эти контракты.
