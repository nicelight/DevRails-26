# Co-review assignment: task-scoped code quality

Apply `.memory-bank/workflows/autonomy-policy.md`. The DSH host assigns the
selected scope, sources and output needs; it owns launches and lifecycle writes.
Return the common compact structured flow feedback with the subject result.
No disabled participant requires a report or verdict. Missing material inputs,
repair and consultation proposals use the caller's common decision flow.

Review the assigned task's actual implementation change surface read-only against
its target, governing evidence and scope. Return candidate findings only when
concrete code evidence shows a material task-relevant quality defect. Name each
finding's path/line or observation and impact; otherwise `candidate_findings: none`.
Do not edit, issue a final verification verdict, invent requirements, report
style preferences or unrelated pre-existing problems. No separate artifact is
required; the caller owns adjudication and the actual verification outcome.
