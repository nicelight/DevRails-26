# Papercuts

- A broad parallel inspection command exceeded the tool output budget and was
  truncated; the affected files were reread with targeted commands.
- `npm run test:install-sync` fails on a pre-existing stale assertion: the
  test expects `stops only the selected feature`, while the canonical command
  says `stops` followed by `only the selected feature` on the next line.
- An `rg` probe containing Markdown backticks was interpreted by the shell as
  command substitution; the probe was rerun with a safe pattern.
- A broad patch-history search for the removed SDD helper exceeded the output
  budget; the relevant commit and branches were inspected with scoped queries.
- A `jq` pipeline failed to parse the historical project's doctor output; the
  report was captured to a temporary file and parsed with Node instead.
- An ad-hoc Node predicate probe over-escaped the `PASS` regex and reported a
  false negative; the deployed doctor result and corrected probe were used.
