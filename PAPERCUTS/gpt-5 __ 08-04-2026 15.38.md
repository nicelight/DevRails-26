# Papercuts

- A `test-install-sync` assertion matched a Markdown sentence as one contiguous
  string and produced a false failure when the canonical text wrapped between
  lines. Contract assertions should match stable fragments or normalize
  whitespace when line wrapping is irrelevant.
- Command safety rejected an explicit `mktemp -d` cleanup guarded to `/tmp/*`
  before the isolated install smoke could start. For ad hoc smoke targets in
  this environment, omit recursive cleanup and let normal temporary-directory
  maintenance remove them.
- A repository search pattern containing Markdown backticks was passed through
  a double-quoted shell command, so Bash attempted command substitution and
  emitted syntax errors. Use single-quoted patterns without embedded shell
  interpolation for Markdown searches.
