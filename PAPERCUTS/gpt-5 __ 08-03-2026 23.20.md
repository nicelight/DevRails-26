# Papercuts

- `kiss-architect.md` requires `.memory-bank/roles/architect.md`, but this source-only checkout has no deployed Memory Bank. Invoking the project-local skill therefore blocks before architecture analysis unless the working project is bootstrapped or synced first.
- A broad multi-file `apply_patch` for the boundary-map template failed because one large context block did not match exactly. Splitting the edit into narrow patches made the change straightforward.
- A combined isolated-install verification command was rejected before execution because its temporary-directory cleanup used `rm -rf`, even though the target came from `mktemp -d`. Re-running without destructive cleanup avoids the policy mismatch.
- The first standalone deployed `mb-lint` probe invoked the target script while keeping the source-repo cwd, so it reported a missing `.memory-bank`; the surrounding shell also returned the later `wc` status. Running the same script with the bootstrap target as cwd gives the meaningful result.
- One `write_stdin` poll returned a tool-side JavaScript syntax error while the install-sync process continued normally; the next poll returned the successful test result.
