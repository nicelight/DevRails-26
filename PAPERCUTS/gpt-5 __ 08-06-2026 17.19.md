# Papercuts

- A combined read of several long canonical instruction files was silently truncated after reporting the warning at the end of the tool result. The relevant ranges had to be reread separately to avoid evaluating a partial workflow contract.
- A read-only `rg` command used a backtick-bearing pattern inside a double-quoted shell command, so the shell attempted to execute `planned|ready`. The file scan still returned partial matches, but the pattern needed safer quoting.
